# Guía de Compilación Soberana JEGL

Ejecuta estos comandos para blindar tu código al 100%:

1. Instala herramientas: `pkg install clang python numpy` y `pip install cython`
2. Compila: `python setup.py build_ext --inplace`
3. Asegura: `rm tetrax_sonic_core.py setup.py`

Ahora tienes un binario .so impenetrable.
